# My First internship

This project created for the ApexPlanet
45-Day Web Development Internship.

## About the Project

This project demonstrates the fundamentals of HTML, CSS,
and JavaScript through a simple, responsive webpage.

## Features

- Semantic HTML structure
- Styled layout using CSS
- Responsive design for smaller screens
- Interactive JavaScript welcome button
- Navigation link to the About section
- External learning resource link

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Files

- `index.html` — webpage structure and content
- `style.css` — visual styling and responsive layout
- `script.js` — welcome button interaction

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Click the "Say Hello" button to test the interaction.
